# 三方成品工牌对接协议（L3 二开接入 · D24）

> 面向三方工牌厂商/平台的通用推送接入协议。服务端模块：`server/partner.js`；端点：`POST /api/partner/push`（公开，验签自鉴权）。

## 1. 接入配置

| 配置项 | settings 键 `partner` | 环境变量 | 说明 |
|---|---|---|---|
| App ID | `app_id` | `PARTNER_APP_ID` | 平台分配 |
| App Secret | `app_secret` | `PARTNER_APP_SECRET` | 平台分配；v3 模式要求长度 16/24/32 字节 |
| 明文放行 | `allow_plain` | `PARTNER_ALLOW_PLAIN=true` | 仅限内网调试；生产一律走签名模式 |

未配置时端点返回 503。

## 2. 鉴权三版

| 版本 | 方式 | 说明 |
|---|---|---|
| v1 | 明文（无签名头） | 须服务端显式 `allow_plain`，否则 403 |
| v2 | 头部签名（推荐） | `Sign = md5(timestamp + requestId + appId + appSecret)`；头：`Api-Version: v2` / `App-Id` / `Request-Id` / `Timestamp` / `Sign`；时间戳 10 分钟窗口防重放 |
| v3 | 签名 + AES-CBC 加密 | 同 v2 验签；body 为 base64 密文（前 16 字节为 iv 前缀占位，key=appSecret 原文，iv=key 前 16 字节） |

验签失败 401；解析失败 400。

## 3. 统一信封

```json
{ "dataType": "AudioText", "timeStamp": 1734835200000, "deviceNo": "861234051234567", "data": { ... } }
```

`deviceNo` 为设备 IMEI（15 位数字，直传不过脱敏）；落库映射到 `devices.device_key`。

## 4. dataType 支持

| dataType | 落地 | 说明 |
|---|---|---|
| `AudioText` | communications | 转写推送：`data.segments[]`（startTimeStr/speakerId/text/dateStart/endMillisecond）拼装说话人前缀文本，**入库前一律脱敏（CMP-07）**；按三方文件名幂等（新建/回填），owner 取设备绑定人，scene 取设备默认场景；LLM 自动分析接线 |
| `HeartbeatLog` | devices + device_logs | 心跳：设备幂等 upsert（online/电量/固件/型号），台账动作日志 |
| `Audio` | 录音文件 + communications | multipart（字段名兼容带/不带引号）：录音落盘 `data/recordings/partner/<deviceNo>/`，按文件名幂等挂 `audio_path` |
| `LoginLog` / `ControlLog` / `UploadLog` / `DebugLog` | device_logs | 台账动作日志 |

不在通用层：GPS 定位（位置数据合规敏感，按需求另行设计）、合并录音下载、厂商主动查询 API（按具体厂商文档适配）。

## 5. 归属保护

- 设备 `owner` **只填空不覆盖**——真人绑定永不被平台同步冲掉（同步归属保护）。
- 转写/录音按三方文件名幂等：重复推送不产生重复记录，后到转写回填同一记录。

## 反哺过程中的方法沉淀

- **断言前置依赖自检**：越权负例断言若放在建测试账号的段之前，login 401 静默失败会让断言以 admin 身份假通过——负例断言必须与账号创建同段或显式校验 login 状态。
- **同型清零靠静态断言兜底**：前端回落类改动配套「页面文本静态断言」，本轮实测逮住看板页第五处漏改。
- **改库模拟故障做端到端断言**：卡死救援/离线判定直接改临时库造状态（analyzing/last_seen_at 过期）→ 触发端点 → 读回验证，不满足于端点 200。

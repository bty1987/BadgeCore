# 03 软件 PRD Ⅰ：录音采集与沟通分析（销售场景核心）

> 版本 v0.1｜2026-09-07｜状态：待评审
> 上游：[01-产品主PRD](01-产品主PRD.md) §3.2 场景 S2/S3、[02-硬件PRD](02-硬件PRD.md) FW 协议
> 对标依据：SaleSmart 实测拆解（本册标注 ★ 的功能均为 SaleSmart 已实拍验证的功能，功能面 1:1 对标）

---

## 1. 范围

本册覆盖：录音采集三入口、实时转写管道、说话人标注、沟通记录管理、AI 分析报告输出。
不覆盖：分析模型配置（→04 册）、AI 模型选型与指标（→06 册）、全员工牌功能（→05 册）。

## 2. 角色与前置条件

- 使用者：已开通「录音授权」的员工（默认销售/顾问角色，授权由管理员配置，见 04 册 ADM-301）
- 设备：已绑定工牌终端（REC-01）；或无工牌时使用手机麦克风（降级路径 REC-10）
- 合规前置：本企业已完成录音告知配置，员工已签知情同意（07 册 CMP-01/02），未满足时「立即录制」入口置灰

## 3. 功能需求

### 3.1 发起沟通三入口（对标 SaleSmart「发起沟通」下拉 ★）

| 编号 | 功能 | 需求描述 | 优先级 |
|---|---|---|---|
| REC-01 | 立即录制 | App 首页「立即录制」：选择工牌（已连接默认）或手机麦 → 关联客户（可选，支持「先分析后关联」模式 ★ 全局配置项）→ 选择沟通流程/环节（可选）→ 倒计时 3-2-1 → 开始。录制中显示实时波形、时长、电量、信号强度 | P0 |
| REC-02 | 安排沟通 | 预约沟通计划：时间、参与人（内部/客户）、客户、沟通流程、需采集的信息收集字段（如房屋概况/预算 ★，字段由管理后台配置）→ 到点提醒（App 推送 + 工牌震动） | P0 |
| REC-03 | 上传录音 | 支持历史音频导入：mp4/mp3/m4a/aac/wav，单文件 ≤ 1GB，时长 ≤ 5h（★ SaleSmart 实证限制）；上传时绑定沟通计划/客户/环节/主题（≤50 字）★ | P1 |

| REC-07 | 暂停/继续/结束 | 支持手动暂停继续；结束后展示「处理中」状态（转写→分离→分析三阶段进度） | P0 |

| REC-10 | 手机麦降级 | 无工牌/工牌故障时用手机麦录制，功能全兼容，报告中标注采集来源 | P1 |
| REC-11 | 过短保护 | 录制 <30s 结束时提示「录制时长过短」并给出收音建议（★ SaleSmart 实证文案）；默认不生成报告，可强制提交 | P1 |
| REC-12 | 客流切分 | 长录音（门店接待场景）按静音段+语义自动切分为多场沟通，人工确认合并/拆分（★「客流切分」全局配置实证） | P2 |

### 3.5 音频源适配器（架构约束，v0.1 新增）

伴生 App 与服务端一律通过「音频源适配器」抽象对接硬件：定义统一接口（连接/推流/电量/状态），开发期 ESP32-S3 载体、量产工牌各写一个适配器——硬件换代上层零改动。第一公里已按此实现（`hardware/receiver/receiver.js`，xiaozhi 协议适配器）。

## 4. 沟通分析报告（分析引擎输出物）

> 模型与指标验收见 06 册；本节定义报告信息结构与交互。

| 编号 | 模块 | 内容 | 优先级 |
|---|---|---|---|
| ANA-01 | 全文摘要 | 3~5 句结论先行摘要 + 关键信息抽取（时间/地点/预算/下一步） | P0 |
| ANA-02 | 分段摘要 | 按沟通环节（流程节点）分段总结，环节由沟通流程配置映射（04 册） | P0 |
| ANA-03 | 客户立场 | 认同点 / 顾虑点 / 未提及项三维列表，每条挂原文证据（可点击跳转字幕）；立场变化曲线（★「客户立场变化趋势」实证） | P0 |
| ANA-04 | 竞品分析 | 识别提及的竞品（对标企业配置的竞品库），竞品声量雷达图 ★、我方优劣势对比、应对话术建议 | P0 |
| ANA-05 | 意向度评估 | 成交模型得分（模型由管理后台配置），意向等级（高/中/低），得分变化趋势；仅 1 次沟通不显示变化曲线（★ 实证规则） | P0 |
| ANA-06 | 任务达成 | 对照任务模型的检查项逐项判定：完成/未提及/不充分 三态 + 判断依据原文（★ 实证三态定义） | P0 |
| ANA-07 | 能力评估 | 对照能力模型逐项打分，雷达图呈现（个人 vs 团队平均 ★ 首页实证）；关联改进建议 | P1 |
| ANA-08 | 违规检测 | 命中违规项列表，每条：违规项名称/触发片段原文/严重级/处置状态；未检出时明确提示「已完成全量违规项检测，未发现任何违规内容」（★ 实证文案） | P0 |
| ANA-09 | 沟通总结模板 | 按环节套用企业自定义总结模板（★ 管理后台「沟通总结-维度/模板」实证），如上门量房模板输出：房屋概况/居住痛点/预算/方案反馈 | P1 |
| ANA-10 | 待办生成 | 从承诺事项自动提取待办（「我下周把方案发您」→ 待办+日期），可推送工牌震动提醒 | P1 |
| ANA-11 | 上次沟通回顾 | 打开同一客户时展示上次沟通摘要/未解决项/竞品提及提醒/立场反对提醒（★「上次沟通回顾」实证） | P1 |

## 5. 非功能需求

| 类别 | 需求 |
|---|---|
| 时效 | 沟通结束 → 转写完成 ≤ 音频时长 ×0.3；转写完成 → 报告生成 ≤ 3 分钟（P95） |
| 准确率 | ASR 字错率 ≤ 5%（普通话安静）、≤ 8%（门店噪声 65dB）；说话人分离准确率 ≥ 92%（06 册详） |
| 容量 | 单企业沟通记录保存 ≥ 3 年（可配置，07 册数据留存） |
| 并发 | 单企业峰值并发录制路数 ≥ 200；平台 10 万路接入预留 |
| 可靠 | 音频上传断点续传，完整率 ≥ 99.5%；上传失败自动重试 3 次 + 人工重传入口 |
| 安全 | 音频与转写全程 TLS；存储加密；访问审计（07 册） |

## 6. 验收标准（节选）

1. REC-01：从点击「立即录制」到听到提示音 ≤ 2s；录制中杀 App 重启，录制不中断（工牌端继续采集+缓存）。
2. REC-05：1 小时沟通产生 ≥ 5 个分段小结，且最终报告引用分段内容。
3. REC-08：飞行模式录制 30 分钟 → 联网后 5 分钟内补传完成且内容完整（哈希校验）。
4. ANA-03：立场列表每条可点击跳转到字幕对应位置，误差 0 条。
5. ANA-08：在包含「承诺0增项」样本的测试集上，检出率 ≥ 90%，误报率 ≤ 5%（06 册测试集）。

## 7. 开放问题

1. 实时辅助（沟通中推送话术）一期做「规则触发」还是「LLM 实时流」？建议一期规则触发（延迟可控），二期 LLM 流式（见 06 册 AI-09）。
2. 视频录制（门店接待）是否列入二期，涉及硬件摄像头选型，需产品决策。
3. 多人同时说话（插话）场景分离准确率目标是否放宽到 90%，待试点数据。

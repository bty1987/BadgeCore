# 04 软件 PRD Ⅱ：管理后台与权限

> 版本 v0.1｜2026-09-07｜状态：待评审
> 对标依据：SaleSmart 管理后台实拍（9 大配置域 + 我的企业 10 个管理项，菜单树 1:1 对标后按我方场景增删）

---

## 1. 范围

本册覆盖：管理后台（沟通配置引擎 + 组织权限 + 全局配置 + 开放平台）。
不覆盖：HR/行政专属功能（考勤/门禁/发卡 → 05 册）、分析模型算法细节（→ 06 册）。

## 2. 信息架构（一期菜单）

```
管理后台
├─ 沟通配置
│  ├─ 信息收集        （沟通计划字段：名称/类型/说明/采集问题示例）
│  ├─ 成交模型        （名称/启用/场景说明；模型项=关键行为检查单）
│  ├─ 任务模型        （任务项 + 任务模型，支持导入）
│  ├─ 能力模型        （能力项 + 能力模型：能力名称/行为表现定义）
│  ├─ 沟通总结        （按环节配置总结模板）
│  ├─ 沟通分析        （分析维度启用/排序：客户立场/竞品/风险/成交模型…）
│  ├─ 沟通流程        （流程 = 环节序列；通用流程 + 业务线定制流程）
│  ├─ 违规检测        （违规项 + 违规模型；导入导出）
│  └─ 竞争对手        （竞品库：名称/产品/优劣势素材）
├─ 客户管理           （客户列表 / 自定义字段 / 画像配置）
├─ 洞察配置           （洞察分类：品牌信任/商务报价/产品价值…可增删）
├─ 风险预警           （沉默/立场反对/竞品提及，阈值可配，启用/禁用）
├─ 知识库             （知识类目：FAQ/异议处理/竞品应对/商务政策…）
├─ 案例库             （优秀案例 + 金牌话术审核发布）
├─ 全局配置           （见 §4）
├─ Ask AI             （双视角助手配置、常见提问、定时推送任务）
├─ 我的企业
│  ├─ 组织架构 / 员工名册 / 部门管理 / 岗位管理 / 职级管理
│  ├─ 恢复账号 / 团队设置 / 字段设置
│  ├─ 角色权限        （见 §5）
│  └─ 开放平台        （API 密钥/回调/日志）
└─ 设备管理（新增，SaleSmart 散点在用户侧，我方独立成域，联动 05 册）
   ├─ 设备台账        （编号/型号/固件版本/电量/状态/持有人）
   ├─ 绑定解绑审批
   ├─ 操作日志        （查询/导出 ★ 对标 SaleSmart badge operation-log）
   └─ 固件升级管理    （灰度策略）
```

## 3. 沟通配置九大域需求（ADM-01x）

| 编号 | 域 | 需求要点 | 优先级 |
|---|---|---|---|
| ADM-011 | 信息收集 | 自定义字段（文本/单选/多选/数字/日期），字段说明支持写入「采集问题示例」（★ 实证：「房屋概况」字段附 3 个采集问句）；字段随沟通计划下发到 App 供沟通中/后填写 | P0 |
| ADM-012 | 成交模型 | 多模型；每模型含检查项清单（从成交沟通提炼）；启用状态、场景说明（★ 实证字段）；产出=意向度评分依据 | P0 |
| ADM-013 | 任务模型 | 两级结构：任务项（原子动作）→ 任务模型（组合）；支持 Excel 导入（★ 实证「导入」）；产出=沟通任务达成率 | P0 |
| ADM-014 | 能力模型 | 能力项（能力名称+行为表现定义）→ 能力模型；产出=能力雷达评分维度 | P1 |
| ADM-015 | 沟通总结模板 | 按环节配置模板（★ 实证：上门量房/方案反馈模板）；模板字段引用信息收集字段 | P1 |
| ADM-016 | 沟通分析维度 | 启用/禁用各分析维度并排序（★ 实证：客户立场/竞品情况/风险项/成交模型为系统内置维度） | P0 |
| ADM-017 | 沟通流程 | 流程=环节序列；环节可关联信息收集字段/总结模板/任务模型（★ 实证「关联」列）；系统预置「通用流程」，行业流程可导入 | P0 |

## 7. 验收标准（节选）

1. ADM-018：创建违规项时，「典型话术示例」「非违规判定说明」为必填（保证语义检测质量），发布后 10 分钟内对新增沟通生效。
2. ADM-312：为「部门经理」角色配置数据范围=本部门后，该角色登录仅可见本部门沟通记录，越权 API 返回 403 且记录审计。
3. ADM-206：导入 200 个热词后，新录制沟通中热词识别错误率下降可量化（对比测试，06 册 AI-02 验收）。
4. ADM-211：禁用物理键后，对应设备按键长按无响应，App 端显示「企业已禁用物理录音键」。

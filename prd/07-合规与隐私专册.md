# 07 合规与隐私专册

> 版本 v0.1｜2026-09-07｜状态：待评审（法务前置审阅项）
> 本册是硬约束：凡与本册冲突的产品需求一律不通过评审。
> 适用法域：中国大陆（个保法/数安法/网安法/民法典人格权编/劳动法域）；出海另增 GDPR 评估。

---

## 1. 两大合规主线

1. **录音合规**：对客户沟通录音涉及客户个人信息与商业秘密；对员工录音涉及劳动者权益。处置不当 → 民事侵权/行政处罚/证据无效三重风险。
2. **员工数据合规**：考勤/定位/绩效类数据属员工个人信息，需最小必要 + 告知同意 + 分域隔离（防止「沟通分析数据」被滥用为考核工具）。

## 2. 需求清单

### 2.1 录音告知与同意（CMP-01x）

| 编号 | 需求 | 优先级 |
|---|---|---|
| CMP-01 | 员工知情同意：首次启用录音功能必须完成协议阅读+签署（电子签存档），未签署则录制入口不可用 | P0 |
| CMP-02 | 客户告知：①物理场景告知——门店/展厅张贴告知标识；②口头告知——录制启动提示音 + 销售开场话术模板（由系统在首屏提醒）；③拒录即停——客户明确拒绝时销售一键停止并不留缓存 | P0 |
| CMP-03 | 电话/线上沟通不采集（一期仅线下面对面场景），避免通信秘密问题 | P0 |
| CMP-04 | 告知内容要素：录音目的/范围/保存期限/查询联系方式，模板由法务定稿并支持企业定制 | P0 |
| CMP-05 | 物理录制键与告知联动：企业若禁用开场提醒（04 册 ADM-211 相关），则必须强制保留提示音（不可配置），保证客户可感知 | P0 |

### 2.2 数据最小化与边界（CMP-05x）

| 编号 | 需求 | 优先级 |
|---|---|---|
| CMP-05 | 录音范围最小化：仅业务模式录制；全员模式麦克风硬件级断电（02 册双模式状态机，杜绝常开监听疑虑，作为安全卖点宣传） | P0 |
| CMP-06 | 无关人员保护：闲聊/私下场景检测到非业务对话（可配置时段如午休）自动停止标记，提示确认 | P2 |
| CMP-07 | 敏感信息过滤：转写与报告中自动脱敏身份证号/银行卡号/手机号（部分掩码显示），原文音频不受影响但检索屏蔽 | P1 |
| CMP-08 | 数据留存策略：默认音频 180 天、转写文本 3 年、报告 3 年，企业可配置但不得低于纠纷取证建议期；到期自动删除并出删除证明 | P0 |
| CMP-09 | 分域隔离：考勤/门禁数据与沟通分析数据分库；HR 角色默认不可访问沟通数据；考核场景使用沟通数据须单独授权（法务条款支撑） | P0 |
| CMP-10 | 离职员工数据：其个人数据（声纹/个人信息）删除；其产生的客户沟通记录属企业资产，按 CMP-08 留存（协议中明确权属） | P0 |

### 2.3 客户权利响应（CMP-11x）

| 编号 | 需求 | 优先级 |
|---|---|---|
| CMP-11 | 客户行使查阅/复制/删除权：企业可在后台按客户检索其相关录音与报告并导出/删除；响应流程 ≤ 15 个工作日 | P1 |
| CMP-12 | 客户异议标记：客户对某次沟通提出异议后，该记录进入冻结区（不可编辑/分享），等待法务处置 | P1 |

| 编号 | 需求 | 优先级 |
|---|---|---|

## 3. 关键交互的合规设计（产品侧落地）

1. **首次启用流程**：员工登录 → 录音协议（逐屏阅读）→ 电子签 → 播放「合规操作 3 分钟」视频 → 开通。
2. **录制启动**：点击录制 → 若当日未做过「告知检查」（企业上传的告知物料在有效期）弹窗确认 → 提示音 → 开始。
3. **报告页脚**：所有 AI 报告固定脚注「以上内容由 AI 生成，仅供参考」（P0）。
4. **员工数据面板**：员工可在 App 内查看「关于我的数据」：我的录音清单/谁查看过/留存到期时间（透明化，缓解抵触）。

## 4. 风险清单（法务评审输入）

| 风险场景 | 等级 | 缓解 |
|---|---|---|
| 客户不知情录音被诉 | 高 | CMP-01~05 全链路；保单（产品责任险）评估 |
| 企业将沟通数据用于裁员/绩效争议 | 高 | CMP-09 分域 + 使用授权条款 |
| 员工离职带走录音（商业秘密） | 中 | 下载水印 + 导出审批 + 审计 |
| LLM 幻觉导致报告误导商业决策 | 中 | ANA 全部条目强制原文引用可溯源；AI 生成标识 |
| 跨境数据（外企客户） | 低（一期） | 一期仅境内部署，出海前重评估 |

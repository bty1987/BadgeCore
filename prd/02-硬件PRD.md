## 0. 总体接入方案（导读）

```
【工牌终端】                【手机】                  【云端】
4麦MEMS阵列(16kHz/24bit)
   ↓ I2S/TDM
主控SoC(BES2600)内置DSP
 波束成形+降噪+回声消除
   ↓ Opus压缩(~24kbps)
   ├─ 实时流: BLE 5.3 ──→ 伴生App ──WSS──→ 流式ASR(实时字幕)
   │                        │
   └─ 本地缓存(落盘)         └─ 断连时:工牌先存NAND,
        ↑ 蓝牙重连后          App上线自动补传(断点续传)
        └──────断点续传──────┘
                                云端: 转写→说话人分离→LLM分析→报告

身份/门禁: NFC安全单元 ──→ 门禁读头（独立通道，不依赖录音链路）
全员待机: BLE信标(考勤) + 墨水屏静态显示（功耗微安级）
```

三大接入决策：
1. **传输**：一期 BLE 桥接手机（SaleSmart 已验证、省 BOM、免蜂窝认证）；4G 二期
2. **主控**：恒玄 BES2600 首选（音频 DSP 优先）；SiFli SF32LB52x 第二候选（带屏低功耗，DayoTag 同款，EVT 前实测对比）
3. **麦克风**：4 麦数字阵列（5m 拾音/说话人分离的物理前提），不用单麦模拟方案

## 1. 产品形态定义

### 1.1 形态与佩戴

| 项 | 需求 |
|---|---|
| 形态 | 胸牌式（对标讯飞「不挂脖不入耳」与 SaleSmart 卡片形态），圆角矩形 |
| 尺寸 | 目标 ≤ 86mm × 54mm × 12mm（兼容标准工牌卡套视觉比例），量产目标厚度 ≤10mm |
| 重量 | ≤ 45g（含电池） |
| 佩戴 | 标准挂绳孔 + 磁吸背夹 + 金属挂扣三种配件，快拆 |
| 屏幕 | 2.13" 墨水屏（e-paper，296×128 起），断电保持显示 |
| 指示 | RGB LED ×1（状态）、震动马达 ×1（通知/提醒） |
| 按键 | 物理录音键 ×1（长按 3s 启停，可远程禁用——对标 SaleSmart「工牌物理录制按键」配置项）、电源/模式键 ×1、复位孔 ×1 |
| ID/CMF | 一期黑白双色；正面丝印企业 Logo 区可定制；IP54（生活防泼溅） |

### 1.2 双模式定义（与 05 册联动）

| 模式 | 典型功耗态 | 触发 |
|---|---|---|
| 全员模式（默认） | BLE 信标广播 + 墨水屏静态显示，MCU 低功耗睡眠；**麦克风硬件级断电** | 上电默认 |
| 业务模式（录音） | 麦克风阵列 + BLE 音频流传输 | App 下发指令或物理键长按 |

## 2. 系统框图与模块选型

### 2.1 系统框图

```
                 ┌───────────────────────────────┐
                 │           主控 SoC             │
                 │  (BLE 5.3 + Audio DSP + MCU)  │
                 │                               │
 MEMS 麦克风×4 ──→ I2S/TDM ──→ Audio DSP(波束/降噪) │
 SPI Flash 16MB ←→ QSPI                          │
 e-paper 2.13" ←→ SPI                            │
 NFC(门禁)     ←→ I2C  ──→ NFC 安全单元            │
 震动/LED/按键 ←→ GPIO                           │
 电源管理 PMIC ←─ 锂电 500~800mAh ─ USB-C 充电     │
 WiFi 模组(可选配)←→ SDIO/UART                    │
 六轴 IMU       ←→ I2C（佩戴检测，源自 DayoTag 参考）│
                 └───────────────────────────────┘
```

### 2.2 主控选型对比

| 候选 | 代表芯片 | 优势 | 风险 | 建议 |
|---|---|---|---|---|
| 恒玄 | BES2500/2600 系列 | 蓝牙音频旗舰，DSP 算力足（双麦/三麦降噪成熟），耳机行业量产验证充分 | 单价偏高，开发资源紧张 | **首选**：BES2600 |
| SiFli | SF32LB52x（如 SF32LB525） | 穿戴级带屏 BLE MCU，屏显/低功耗待机强；国产、嘉立创生态开发快（DayoTag 全天录音已验证其功耗） | 音频 ADC 前端弱，4 麦阵列 DSP 算力吃紧，需外挂音频 codec/DSP（双芯片 +15~20 元） | **第二候选**：全员模式强的备选 |
| 杰理 | AC63X/AD69X 系列 | 性价比高、录音笔行业方案成熟、货期稳 | DSP 算力上限低于恒玄 | 备选：成本敏感时降级 |
| 乐鑫 | ESP32-S3 | WiFi+BLE 一体、生态最好（**本项目开发载体 1.75C 即基于此**） | 音频前端弱，量产音频场景不推荐 | 开发/调试平台 |

> 结论：一期「BLE 桥接 App」路线用 **恒玄 BES2600（首选）/ 杰理（备选）**；「SF32(屏显/信标) + 外挂音频 DSP」双芯片 vs「BES2600 单芯片」在 EVT 前实测对比。选型评审前由硬件团队输出功耗实测（同载荷 16kHz×4ch 采集 + BLE 上传）。

### 2.3 音频前端

| 项 | 需求 | 对标依据 |
|---|---|---|
| 麦克风 | MEMS 数字麦 ×4（阵列排布：上 2 下 1 + 底部 1 或四角布阵），SNR ≥ 64dB | 科金 4 麦/50dB；讯飞 2+1；我方取 4 麦上限配置 |
| 拾音距离 | 5 米清晰拾音（A 计权，1kHz 校准） | 行业统一标称 5m |
| 采样 | 16kHz / 24bit，多通道同步采集（TDM） | ASR 行业标准 16kHz（科金同参数） |
| 前端处理 | 波束成形 + 回声消除(AEC) + 自动增益(AGC) + 降噪(NS)，DSP 端完成 | 讯飞「阵列组合降噪」、科金「声学降噪 95%」 |
| 本地缓存 | SPI NOR 16MB 起选配至 NAND 16GB（讯飞 16G 存储对标），支持离线录音环形缓存 | SaleSmart「离线录制+联网自动补传」实证需求 |
| 音频编码 | BLE 传输段：ADPCM/Opus 压缩（带宽 ≤ 200kbps）；缓存段：Opus 16kHz | 保证 BLE 吞吐与 App 端透明解压 |

### 2.4 无线与近场

| 模块 | 需求 | 用途 |
|---|---|---|
| BLE 5.3 | ≥ 2M PHY，音频流稳定传输 ≥ 10m 视距；LE Audio 可选 | 录音桥接、指令通道、考勤信标、OTA |
| WiFi 2.4G（配 / 不配两版评审） | 仅 OTA + 离线录音批量补传用，一期默认不配（成本） | 缩短「离线→补传」链路 |
| NFC | ISO 14443A，兼容主流门禁读头协议（Mifare/CPU 卡模拟），安全单元存储门禁密钥 | 门禁、身份刷卡（05 册 ALL-201） |

### 2.5 电源

| 项 | 需求 |
|---|---|
| 电池 | 锂聚合物 500~800mAh，通过 UN38.3 / IEC62133 认证 |
| 续航 | 录音模式 ≥ 12h 连续（对标讯飞 12h+）；全员模式 ≥ 5 天（BLE 信标 1s 间隔 + 屏静态） |
| 充电 | USB-C，磁吸充电线选配件（对标讯飞充电数据坞：一期不做坞，二期做 12 位多充坞） |
| 充电时长 | ≤ 2h 满充 |
| 保护 | 低电量自动停录并保存（对标 SaleSmart「低电量停录」实证文案）、过充过放过温保护 |

## 3. 固件需求（FW-）

|---|---|---|
| FW-01 | 双模式状态机：全员模式 ↔ 业务模式，App 指令/物理键切换，切换响应 ≤ 500ms | P0 |

| FW-05 | 电量/信号状态上报（1min 周期 + 状态变化即时），App 与云端状态一致（对标 SaleSmart 电量/信号/在线状态三件套） | P0 |
| FW-06 | 低电量停录：≤10% 自动停录、保存缓存、震动+LED 提示 | P0 |

| FW-11 | 物理录音键可配置开关（云端配置 → App 下发 → 固件生效，对标 SaleSmart「工牌物理录制按键」管理项） | P1 |
| FW-12 | 出厂测试模式：产测治具接口（射频/音频/按键/屏/电池一键测试） | P0 |
| FW-13 | 闲时熄屏/省电：无操作 N 分钟熄屏（AMOLED 用 Display OFF 指令 0x28 / 亮度指令 0x51），触摸/按键唤醒——开发载体 1.75C 实测需求 | P1 |

## 9. 实施路径（v0.2 新增）

**开发期（当前）**：开源开发板做软件载体——微雪 ESP32-S3-Touch-AMOLED-1.75C（已到货验收，见 hardware/HARDWARE-LOG.md），通过「音频源适配器」抽象层开发全部软件链路；QS668/CB08 方案已否决（电商无货）；DayoTag 作参考设计（授权禁商用）；百度度目可购一套作交互对标。

**产品化期**：深圳方案商 Turnkey（恒玄 BES2600 参考设计定制）：我方出 ID/结构/固件界面需求，方案商出原理图 PCB+底层固件，我方硬件负责人审图验收。询价三要点：①带屏+录音+BLE 量产案例 ②固件源码交付 ③NFC 门禁经验。

**规模化期**：吃透方案商电路后转全自研 layout（严格意义自研）。

### 开放问题（需硬件团队评审回答）

1. BES2600 vs 杰理 vs 「SF32+外挂DSP」同载荷实测功耗差与单价差
2. 墨水屏驱动与主控 GPIO 预算是否冲突
3. NFC 安全单元选型（NXP NTAG 系 vs 国密方案），取决于目标门禁生态（05 册 §3）
4. WiFi 版本是否一期并行（+成本约 25 元）——建议 DVT 后决策

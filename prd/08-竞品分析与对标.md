## 1. SaleSmart 产品拆解（对标基线）

### 1.1 基本信息

| 项 | 内容 |
|---|---|
| 产品 | SaleSmart（x-mate.com），云学堂（yxt.com）灵犀平台出品 |
| 定位 | AI 录音工牌 + 销售会话智能 SaaS（软硬一体） |
| 前端 | NovaGuide v3.6.3，Vue 3 + 自研组件库；Electron 桌面端 + 移动 H5 |
| 后端 | blue.x-mate.com（业务 API）；api-phx-ali.yunxuetang.cn（网关）；WSS 实时通道 |
| 登录 | 手机号/邮箱 + 验证码（腾讯防水墙）、SSO；企业多组织选择 |

### 1.2 功能全景（实测确认）

**销售端**：首页（沟通统计/能力雷达/任务达成/今日日程待办/情报中心）、发起沟通三入口（立即录制/安排沟通/上传录音）、沟通列表（处理状态/赋能状态/导出）、客户列表（11 列字段）、案例库（优秀案例+金牌话术）、指挥舱（实时沟通看板/客户追踪器）。

**管理后台九大配置域**：信息收集 / 成交模型 / 任务模型 / 能力模型 / 沟通总结模板 / 沟通分析维度 / 沟通流程（环节序列，行业定制如家装「走馆带展→上门量房→报价谈判」）/ 违规检测 / 竞争对手。

**我的企业**：组织架构/员工名册/部门/岗位/职级/恢复账号/团队设置/字段设置/角色权限（角色等级+权限树：导航×操作×数据范围）/开放平台。

**全局配置 13 项**（硬件链路相关是金矿）：企业设置、沟通记录查看权限、删除权限、参会人属性设置、沟通详情页设置、语音识别热词、ASR 模型、发言人标注设置、语音切分设置、蓝牙设置、**工牌物理录制按键**、先分析后关联客户、实时辅助。

**硬件链路实证**：工牌编号/电量/信号/在线状态（轮询+WSS 推送双通道）、蓝牙桥接 App、设备级录制互斥、低电量停录、离线录音自动补传、固件升级、设备绑定/解绑/操作日志 API（badge operation-log query/export）、deviceFp 设备指纹。

**AI 11 项**：流式 ASR（xmateasr）、说话人分离与声纹标注、10 分钟/500 字分段总结、分析报告（全文+分段摘要/客户立场三维/竞品声量雷达/意向度成交模型/任务达成三态判定/能力雷达）、违规语义检测（违规项=触发描述+典型话术+非违规判定说明）、实时辅助、访前五智能体（产业信息挖掘机/企业信息侦察机/产品价值演绎家/客户追踪器/商机追踪器）、Ask AI 双视角（SalesCoach/SalesCommander）+定时推送、销冠话术提炼、风险预警（沉默 14/7 天/立场反对/竞品提及）、知识库+学习中心（销售方法论书籍库）。

### 1.3 值得抄的工程细节（实证）

1. 「10 分钟且 500 字」分段总结规则——长沟通体验与成本平衡点。
2. 违规项的「非违规判定说明」——LLM 判活的抗误报设计（如区分「诱导仓促签约」与「正常催签」）。
3. 「仅发言人信息变更时才可重新生成报告」——避免重复分析成本的交互约束。
4. 「仅 1 次沟通不展示变化曲线」「意向度评估产出后自动生成」等空态与降级文案体系。
5. 风险预警阈值行业差异化：b2b 14 天 / b2c 7 天。
6. 设备状态三件套（电量/信号/在线）轮询+推送双通道，弱网文案完备（「工牌信号较弱，录音上传可能较慢」）。

### 1.4 SaleSmart 的不足（我方机会）

1. 只有销售场景，非销售员工无价值——我方全员模式补位。
2. 无身份/考勤/门禁能力——工牌本身的价值面窄，采购决策链短。
3. 深度绑定云学堂 SSO 生态，开放性一般——我方开放平台+IM 生态集成。
4. 无 4G 版（依赖手机桥接）——独立运行场景（门店无手机）受限，我方二期 4G 版可打。

## 3. 竞争策略结论

1. **不对称竞争**：不与讯飞拼 ASR 品牌、不与钉钉拼生态入口，以「全员基础设施 + 配置化分析引擎 + 开放集成」差异化。
2. **基线保证**：SaleSmart 已验证的功能面（尤其沟通配置九域 + 违规语义检测 + Ask AI）为 P0 质量基线，逐项对标验收。
3. **成本优势**：全自研 BOM 控制（≤180 元）+ 无坞设计（一期）打价格带下沿。
4. **数据资产**：全员佩戴 → 沟通数据 + 组织行为数据闭环，长期壁垒。

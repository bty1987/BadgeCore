# 05 软件 PRD Ⅲ：全员工牌扩展（差异化模块）

> 版本 v0.1｜2026-09-07｜状态：待评审
> 定位：本册是对标 SaleSmart 不具备、我方「全员数字工牌」定位特有的能力域（对应主 PRD §1.3 差异化）。
> 依赖：[02-硬件PRD](02-硬件PRD.md) NFC/墨水屏/BLE 信标、[04-软件PRDⅡ](04-软件PRD-管理后台与权限.md) 组织架构与设备管理域。

---

## 1. 范围

- 身份展示（屏显 + 二维码 + NFC）
- 考勤（BLE 无感打卡）
- 门禁（NFC 刷卡，与人行闸机/门锁生态对接）
- 消息通知（工牌端震动 + 屏显 + LED）
- 人员定位与电子围栏（P2）
- 设备全生命周期（发卡/换卡/挂失/注销）

## 3. 技术要点（给后端/App 的约束）

1. **BLE 信标协议**：工牌以 1s 间隔广播 iBeacon 格式（UUID 按 企业+区域 分段），网关/App 上报到定位服务；信标占空比与 5 天续航指标（02 册）联动校准。
2. **门禁密钥安全**：密钥仅存安全单元，云端→App→工牌全程加密下发，App 不可读取明文；挂失名单下发延迟目标 ≤ 30s。
3. **考勤判定**：到达 = 收到 ≥2 个办公区信标且 RSSI ≥ -75dBm 持续 60s；离开 = 5 分钟无有效信标。参数可配置。
4. **消息通道**：优先走 App 长连接转发到工牌（BLE），App 不在线时走工牌 WiFi（若有）或入队等 App 在线补推；推送时效分级（寻呼 P0 级 < 5s，待办 < 1min）。
5. **数据分域**：考勤/门禁库与沟通分析库物理分离，API 网关按角色域鉴权（07 册 CMP-09 细则）。

## 4. 验收标准（节选）

1. ALL-201：500 人办公区，信标打卡与人工记录一致率 ≥ 99%（试点 2 周）。
2. ALL-301：挂失后 30s 内原牌刷门禁被拒。
3. ALL-401：待办推送从云端到工牌震动 P95 ≤ 60s（App 在线）。
4. ALL-603：离职注销后，该设备无法用原账号配对，云端历史数据进入留存期隔离区。

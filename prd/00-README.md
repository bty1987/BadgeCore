## 需求编号规则

- `HW-` 硬件　`FW-` 固件　`REC-` 录音链路　`ANA-` 沟通分析　`ADM-` 管理后台
- `ALL-` 全员扩展　`AI-` AI 能力　`CMP-` 合规
- 优先级：P0（一期必须有）/ P1（一期争取）/ P2（二期及以后）

## 术语表

| 术语 | 含义 |
|---|---|
| 工牌终端 | 员工佩戴的硬件设备（胸牌形态） |
| 伴生 App | 装在员工手机上、与工牌蓝牙桥接的移动端应用 |
| ASR | 自动语音识别（Automatic Speech Recognition） |
| 说话人分离 | 区分录音中"我方/客户/多人"的角色标注 |
| 实时辅助 | 沟通进行中按规则实时推送话术/风险提示 |
| 沟通环节 | 一次沟通中的流程段（如：接待→需求挖掘→方案报价） |
| 沟通流程 | 沟通环节的有序组合，按业务线配置 |
| 成交模型 | 从历史成交沟通中提炼的关键行为指标集 |
| 违规模型 | 违规项的集合，用于合规质检 |
| 客流切分 | 长录音按沟通场次自动切分 |

# BadgeCore · 员工数字工牌

> 软硬一体的全员工牌产品：对全员是「身份 + 考勤 + 门禁 + 通知」智能终端，对销售/服务团队是「AI 沟通赋能」工具。

## 项目简介

市面六家竞品（讯飞/科金/钉钉/明略/云知声/SaleSmart）全部只做「销售录音工牌」，没有一家做「全员工牌」。BadgeCore 把工牌做成公司基础设施：**全员模式**提供身份、考勤、门禁、通知等低功耗终端能力；**业务模式**为销售/服务角色叠加录音 → 实时转写 → LLM 分析报告的完整管线。双模式硬件级隔离，录音双告知、员工数据分域、AI 生成标识三条合规红线一票否决（D1、07 册）。

项目按「对标拆解 → 10 册 PRD → 开发板全链路验证」推进：SaleSmart 已实测逆向拆解（121 路由/43 命名页 + 1531 条文案库），功能面 1:1 纳入 P0；云端 ASR、LLM 分析、管理后台、企微推送均已实测上线；设备端基于小智 AI 开源固件自编译 Fork，已跑通 OTA 自分发、工牌身份面、心跳上报与配网锁定。

## 核心能力

- **工牌终端（固件）**：工牌身份面（层级排版/头像/录音红点计时/电量%）、息屏策略（OK 长按切换/任意键唤醒/空闲 60s 自动息屏、对话期间常显）、OTA 自分发 5 分钟自愈、心跳上报（电量/版本三层链路落库）、配网锁定 `provision_lock` 三态下发 + 热点 WPA2（待上机）
- **语音链路**：xiaozhi 协议录音推流、OPUS→Ogg 封装、讯飞实时听写（实测零字错）、录音转写大模型说话人分离（我方/客户双角色，6 倍速）、会话累积模式（软分段 10min / 每日 18:00 / 手动收口）
- **AI 分析**：沟通报告自动生成（立场带原文引用/意向度评分/违规判活/待办提取）、内部组织四场景模板（sales / meeting / training / talk，改标重析；talk 红线=事实层双向承诺、无情绪评分、参与者对称透明）、Ask AI（关键词检索+权限过滤+来源引用）、智能体（访前准备清单+定时报告）
- **管理后台**：对标九大配置域、数据看板/团队报告、组织架构/角色/数据权限、全员考勤（ALL-201 判定/补卡/记录）、合规三件套（脱敏双层/留存清理/导出水印）、实时辅助（竞品与风险词告警）、企微群推送（定时报告+会议纪要双投，开关默认关）
- **联调工具**：`sim-device.js` 模拟设备推流（无板子全链路可跑）、本地 faster-whisper / 讯飞双云管道转写 CLI、冒烟测试 134 项

## 快速开始（开发）

```bash
# ① 后台（http://localhost:8200，admin/admin123；首次启动自动建库+生成入库令牌）
cd server && node index.js                          # 零依赖，Node ≥22.5 即可

# ② 接收端（板子配网高级选项 OTA 地址指向本机即可切流）
cd hardware/receiver && npm i && node receiver.js   # 监听 8100；配了讯飞凭据则边录边出字

# ③ 打通自动入库（receiver 环境变量，令牌见后台「设置」页）
set BADGE_SERVER=http://localhost:8200
set BADGE_TOKEN=<后台设置页的入库令牌>
#   → 设备录音结束自动进后台，配了 LLM（或 mock）即自动出分析报告

# 没有板子也能全链路联调
node sim-device.js --seconds 5                      # 模拟设备推音频流

# 转写录音
python transcribe.py sessions/<xxx>.ogg small       # 本地 faster-whisper
node asr-xunfei.js sessions/<xxx>.ogg               # 云端·讯飞听写（需 asr.config.json）
node asr-xf-transcribe.js sessions/<xxx>.ogg        # 云端·讯飞转写（说话人分离，需订阅转写时长）

# 后台冒烟测试（自包含临时库）
cd server && node smoke-test.js
```

内网部署：Windows 双击 `deploy/start.bat`；Linux 用 `deploy/docker-compose.yml`。

## 关键结论速查

1. **产品定位**：全员模式（低功耗身份/考勤/门禁/通知）+ 业务模式（录音分析），双模式硬件级隔离
2. **对标基线**：SaleSmart 功能面 1:1 纳入 P0（沟通配置九大域 / 违规语义检测 / Ask AI）
3. **差异化**：市面无「全员工牌」产品，这是采购决策升级的核心卖点
4. **硬件路线**：一期方案商 Turnkey（务实自研），演进全自研；开发载体 ESP32-S3 生态
5. **合规一票否决**：录音双告知 / 员工数据分域 / AI 生成标识（07 册）

## 0. 结论与建议（TL;DR）

| | 形态A 挂脖工牌（竖版） | 形态B 胸牌（横版名牌） |
|---|---|---|
| 外廓 | **57.4 × 88.4 × 12.4 mm**（竖放，挂绳环台局部 +1.2） | **88.0 × 57.0 × 11.2 mm**（横放，全包裹） |
| 面貌 | 竖版工牌：贴纸身份区 + LED 状态灯 + 顶部挂绳，预留录音/SOS 按键孔 | 横版名牌：大面积贴纸名牌面 + LED 状态点，无科技感堆砌 |
| 结构 | 全包裹两件式（主壳+面板），防护完整 | 全包裹两件式，PCB 壳内横置 90° |
| 电池 | 403450 锂聚合物 800mAh（回退 503035/500mAh 只改 bat 参数） | 303035 锂聚合物 250mAh（3.0mm 薄型） |
| 显示 | **基本不搞屏幕（D21）**：身份=印刷贴纸，状态=低耗 LED；板载 SSD1306 默认不开窗（调试可开） | 同左 |
| 喇叭 | **无**（D20） | **无**（同左） |
| 背戴 | 挂绳：双角圆孔（默认）/ 顶部工牌横槽（`eye_style` 切换） | 背夹槽（默认）/ 磁吸盘（`back_style` 切换） |
| 整重估算 | ≈ 57g（PCB 24 + 电池 16 + 壳 14 + 螺丝 2） | ≈ 44g（PCB 24 + 电池 5 + 壳 13 + 螺丝 2） |
| 定位 | **挂脖工牌**：全天佩戴、耐磕碰、持久运行 | **胸牌**：贴胸名字条，轻、薄、低调 |

核心设计决策：

1. **电池舱全开放**（内腔整个掏空，不按元件分格）——S3V19 各元件实际坐标未知，全开放舱对布局误差零敏感，只有 USB/开关/麦克风 3 处开孔需要实测校准（全部参数化）。
2. **两件式螺丝装配**沿用原工程 M2 规格——原工程就是「上盖+背板、M2×4/2×6」，不发明新装配方式；卡扣版列为备选（见待拍板项）。
3. **两形态均无喇叭（09-20 拍板，D20）**——不需要提示音外放硬件。电池舱深由喇叭 5.4mm 解放，A 顺势升 403450(800mAh)。板载 MAX98357 功放保留、固件不启用。
4. **竖版工牌 vs 横版名牌（v4/v5，参照市场样机图）**——两张参照图（竖版智能工牌、DuDuTalk 横版拾音胸牌）说明：辨识度来自**方向与面部构成**。A=竖版（挂绳、贴纸身份区、预留按键区），B=横版名牌（大面积贴纸面 + LED 点）。诚实边界：同一块 85×54 PCB 决定两形态包络互为旋转（≈88×57）——要 90×35 扁条需复刻 v2 小板（参数即插即用）。
5. **基本不搞屏幕（v5 拍板，D21）**——工牌身份是静态信息（姓名/工号/公司），用**印刷贴纸**嵌面板凹槽；动态状态（录音中/待机/绑定）用**低耗 LED 状态灯**（导光柱）。为持久运行让路，屏幕从佩戴形态退役；板载 SSD1306 保留在 S3V19 板上不浪费（壳留 `win_on` 调试开窗），复刻 v2 直接去屏——与 09-13「选板新标准：不要屏、要好麦、要大电池，纯采集形态是终极答案」汇合。
6. **参数化优先于一次成型**——所有临界尺寸集中在两个 .scad 文件头部参数区，实测改动只碰 6~10 个数字。

## 3. 3D 打印工艺与公差

**推荐**：FDM，0.4 喷嘴，0.2mm 层高，**PETG**（耐晒耐汗、韧性好；PLA 亦可打验证版）。3 层壁 + 25% Gyroid 填充。淘宝 3D 打印店直接说：「FDM，PETG，0.2mm 层高，壁厚≥1.2mm，两件，图纸 STL 自带」。

| 项 | 取值 | 说明 |
|---|---|---|
| 面板打印方向 | **正面朝下**（LOGO 与视窗贴热床） | 正面最平整；凸字呈凹印效果好 |
| 主壳打印方向 | 背面朝下、开口朝上 | 螺柱/加强柱竖直打印，强度最好 |
| PCB 装配间隙 | 单边 0.3（`clr`） | PCB 公差 ±0.2 内安全 |
| 面板裙边过盈 | 单边 0.15 | 摩擦预定位 + 螺丝锁紧 |
| 自攻引孔 | Ø1.7（`pilot_d`） | M2 自攻标准底孔；首个打样先试拧，偏紧扩 1.8 |
| 视窗/格栅 | 无需支撑 | 均为通孔 |
| USB 喇叭口 | 外扩 45° | 不吃支撑，插头直插不受阻 |
| 挂绳孔 | 沿 Z 贯通打印 | 环台+加强柱叠层受拉，PETG ≥30N 冗余 |

**装配顺序**（A）：电池泡棉胶贴主壳舱底 → 电池线沿电池边走线槽（403450 与舱壁间 ~10mm）到 PCB 焊点 → PCB 落垫圈台、面板裙边先压入再 4× M2×6 锁紧。（B）：电池泡棉胶贴背板舱内 → 电池线上到 PCB → PCB 落垫圈台 → 面板压入、4× M2×6 锁紧。**贴纸最后贴**：身份贴纸印好覆膜后贴入凹槽（改岗只换贴纸不换壳）。挂绳用**带安全扣（breakaway）**款——挂脖件遇勾拉应断开，这是挂脖形态的安全惯例。

### 3.1 实时上传（需求①）

**支持，且是现状已实测的能力**——链路：板子录音 → WiFi WebSocket 实时推流 → 讯飞流式听写实时转写（逐字级，已真机多轮验证，含 EOS 断句重建会话修复）→ receiver 入库 → 分析。三种数据方式：

| 方式 | 状态 | 说明 |
|---|---|---|
| 实时推流 + 实时转写 | ✅ 现状已通 | 靠 WiFi；会话模式（明确/累积/手动）是服务端逻辑，固件零改动 |
| 实时字幕查看页 | 可选（P3，约 1 天工作量） | receiver 已收实时流，加 SSE 页即可看「正在说」 |
| 断网缓存 + 回连补传 | 量产要求（PRD REC-08），当前固件未实现 | Fork 后可做：本地写 flash 队列，回连补传 |

**限制**：当前两块板（S3V19/1.75C）都只有 WiFi、**无 4G**——室外移动实时上传需换带 4G 的板或量产选型加通信模组；这是选型项，与外壳无关。

### 3.2 电量与待机时长（需求②，估算——到货实测回填）

去屏（D21）去喇叭（D20）后，耗电只剩三块：WiFi、麦克风链路、LED。ESP32-S3 电流估算（3.7V 锂电，可用容量按 80% 计）：

| 工作模式 | 电流估算 | A 800mAh | B 250mAh |
|---|---|---|---|
| 深睡 + 按键唤醒（不连网） | ~0.1mA | 数周 | 数周 |
| 连网静默待机（modem-sleep，按键/IMU 唤醒录音） | ~5-10mA | **3~5 天** | ~1 天 |
| 唤醒词常听待机（AFE + WiFi 连接） | ~40-60mA | **约一天** | 半天 |
| 连续录音实时推流 | ~150-250mA | 3~4 小时 | ~1 小时 |
| 典型混合（每天 1h 会议推流 + 其余静默待机） | — | **2~3 天** | 大半天 |

结论：①「持久运行」的关键是**固件策略而非电池**——不常开唤醒词，用按键/IMU 摇动触发 + modem-sleep 静默待机，A 可达数天；②连续实时转写是高耗电场景，前台固定岗位插电常驻（已拍板原则），移动场景按需开启；③唤醒词常听一昼夜即耗尽 A，只在「随时喊它」体验必要时开启。充电：MCP73831 板载约 500mA，A 约 2h、B 约 40min 充满。量产 PRD「录音 12h/待机 5 天」是墨水屏+专门电源方案的指标，与此开发壳不冲突。

## 4. 参数化使用（OpenSCAD）

1. 装 OpenSCAD（openscad.org，免费，Windows 直接装）。
2. 打开 `hardware/cad/badge_A_necklace_card.scad`，按《到货实测清单》改头部参数区数字。
3. 左上 `part` 变量切 `shell` / `face` → **F6 渲染** → File > Export > Export as STL，导出两个 STL。
4. 形态B 同理（`badge_B_clip_card.scad`）；`back_style` 三选一：`clip`（背夹）/ `magnet`（磁吸）/ `plain`。
5. 直接把 STL 发淘宝打印店（¥10~20/套，FIRMWARE-PLAN §4b 已列预算）。

## 5. 到货实测清单（09-25 板子到手后）

卡尺实测以下 9 项 → 改 .scad 参数 → 重导 STL → 首轮打样（建议 A、B 各 2 套，PETG + PLA 各一验证）：

| # | 实测项 | 方法 | 回填参数 |
|---|---|---|---|
| 1 | PCB 长×宽×厚 | 卡尺 | `pcb_l / pcb_w / pcb_t` |
| 2 | 4 孔孔心坐标与孔径 | 卡尺量孔心到板边 | `hole_in`（`hole_dx/dy` 自动派生） |
| 3 | USB-C 所在边与中心偏移 | 目视+卡尺 | 需要换边时告诉我改结构（当前假设底边居中） |
| 4 | 拨动开关位置、朝向、拨杆尺寸 | 卡尺 | `sw_x`、槽宽 |
| 5 | （仅调试开窗才需要）SSD1306 外形与位置 | 目视+卡尺 | `win_*`（默认不开窗，D21） |
| 6 | INMP441 进音孔朝向与坐标 | 目视+卡尺 | `mic_x/mic_y`（背面孔→正面孔改法另给） |
| 7 | 最高元件顶高（含模组屏蔽罩/开关柄） | 卡尺 | `comp_h`（原工程 8mm 整机反推约 2.5~3.5，当前 3.4） |
| 8 | 板上按键数量/位置 + 有无板载 LED | 目视 | 按键：`btn_on/btn_positions`；LED：板上没有就保持孔位（导光柱空置无碍） |
| 9 | 整机三档电流（深睡/连网待机/推流） | USB 电流计 | 回填 §3.2 待机表（校准续航估算） |

另实测电池焊点位置，确认走线路径（当前假设：电池线沿舱壁侧槽走）。

## 7. 风险

- **R1 默认尺寸全部未实测**：首轮打样必留 0.3~0.5mm 修配余量；最坏情况局部扩孔重打（¥10 级成本，可接受）。
- **R2 INMP441 进音朝向**：若实际为正面进音，麦克风孔需从背板改到面板（参数已按背出声假设，改法现场给）。
- **R3 电池舱深**：403450 需舱深 4.6mm；若电池与板上底面元件冲突，回退 503035（bat 参数改 50/30/5，总厚 13.4mm）或更薄的 403035/303450。
- **R4 原工程 STL**：FIRMWARE-PLAN §4b 提过可向作者索要原外壳 STL——若拿到，可对照其开孔坐标直接校准本稿参数，实测清单工作量减半。
- **R5 包络互为旋转的诚实边界**：A/B 用同一块 85×54 PCB，包络 ≈88×57 互为旋转，差异化靠方向/面部构成/厚度/重量；要 DuDuTalk 那种 90×35 扁条需复刻 v2 小板（两个 .scad 的 `pcb_l/pcb_w` 即插即用）。
- **R6 LED 依赖**：S3V19 板载 LED 情况未知（可能只有电源指示灯）——导光孔先按设计位留（空置无碍），复刻 v2 正式加 RGB；状态灯语义依赖固件定义。

# 小板集成方案：Seeed XIAO ESP32S3 Sense 可穿戴拾音原型（v1 草案）

- 日期：2026-09-20
- 定位：ESP32 路线的「小板集成」形态——体积最小的可穿戴验证机（对比 DevKitC 拼装/S3V19 成品卡）
- 前提对齐：D20 无喇叭、D21 无屏幕（贴纸+LED）——本方案天然满足，且**零/微焊接（仅电池 2 个焊盘）**
- 服务端：**零改动**（复用现有 WS→讯飞转写→入库→分析全链路，`device` 字段登记新型号即可）

---

## 1. 为什么是它（结论前置）

- 主板 **21×17.5mm**（Seeed XIAO ESP32S3，ESP32-S3R8：8MB Flash + 8MB PSRAM），Sense 扩展层**板载 PDM 麦克风**，主板自带**锂电池充电电路**——录音、充电、WiFi 全集成；
- 外壳可做到 **约 34×56×13（挂脖版）/ 56×34×12（横版胸牌）**——比 v5 的 A/B 壳都小，是「小巧工牌」的真底子；
- Seeed 官方 wiki 有把这块板接入小智的教程（基座验证有据可依）；Fork 只需新增一份板定义；
- 已知代价（诚实账）：①电池是焊盘（全方案唯一焊点，2 个）；②板载天线较弱，壳要留净空；③8MB Flash 跑 Fork 需验证分区；④Sense 的摄像头/SD 卡暂不用（留作未来「拍照存证」伏笔）。

## 3. 硬件组装（零/微焊接）

| 部件 | 接法 | 焊接 |
|---|---|---|
| PDM 麦克风 | Sense 扩展板与 XIAO 主板 **B2B 连接器直插** | 无 |
| 电池 | XIAO 背面 **BAT+/GND 焊盘** | **仅此处 2 个焊盘**（电池买焊好线的，焊到自己板上；或请店家代劳） |
| 录音触发 | XIAO 板载 **BOOT 键（GPIO0）复用为录音键**，壳上按键孔对位 | 无 |
| LED | XIAO 板载充电指示灯 + 壳上 LED 导光点接空闲 GPIO | 预留，v1 可只看板载灯 |
| 充电/刷机/调试 | USB-C 一口三用 | 无 |
| 天线 | XIAO 板载天线——壳内对位留净空区 | 无 |

## 4. 固件方案

1. **基座**：现有 Fork（xiaozhi-esp32 v2.x 系）；
2. **板定义**：新增 `xiao-esp32s3-sense` 板定义——PDM 麦（I2S PDM RX，引脚按 Seeed 固定映射）、无喇叭（D20：音频输出通道置空/静音，提示走 LED）、BOOT 键=录音键。参考 Seeed 官方 wiki 的小智接入教程（若版本与 Fork 有出入，板定义我来适配）；
3. **分区**：8MB Flash 分区表（Seeed 教程已在此板跑通小智，风险可控）——M1 里程碑验证；
4. **省电策略**（对齐 §3.2 结论）：不常开唤醒词——BOOT 按键触发录音 + modem-sleep 静默待机，目标待机数天；
5. **服务端**：零改动。devices 表登记新 `device_key/model`，转写/入库/报告全链路复用。

## 6. 外壳 v6 方案（真实尺寸，无需等待实测）

| 版本 | 外廓 | 结构 | 开孔 |
|---|---|---|---|
| v6A 挂脖版 | ≈ **34 × 56 × 13 mm** | 全包裹两件式（继承 v5 结构语言）：电池层(XIAO 背面/并排) + 板层 | 挂绳（rings/slot 双样式继承）、USB-C、录音键孔（对 BOOT）、LED 导光点、贴纸凹槽、LOGO |
| v6B 横版胸牌 | ≈ **56 × 34 × 12 mm** | 同上，横置（继承 B 名牌构成） | 背夹槽/磁吸、USB-C、贴纸名牌面、LED 点 |

- 内腔布局：XIAO+Sense 叠层（21×17.5×~8）+ 电池 303040（3×30×40）并排/叠放，舱体全开放（沿用 v5 的布局容错设计）；
- 设计基准全部为公开标准尺寸（XIAO 官方 21×17.5），**不依赖板子到货实测**，打样后按 0.3-0.5mm 修配即可；
- 打印工艺同 v5：PETG、0.2mm 层高、面板朝下、无支撑设计。

## 7. 与其它路线的关系（当前全景）

### 7.1 低成本档位评估（09-20 追加：SuperMini / C3 / 小智套件）

用户问：小智套件 ¥70 内、去掉音频输出再省、换 C3 或 SuperMini 能否控成本实现功能。判定：

| 方案 | 全套成本 | 能跑 Fork？ | 备注 |
|---|---|---|---|
| **S3 SuperMini N16R8** + INMP441 + TP4056 + 电池 | **≈ ¥50-60** | ✅ 16MB Flash + 8MB PSRAM | 推荐的最低成本组合；三件拼装、无充电电路无板载麦 |
| 小智套件去掉喇叭件 | ¥40-60 | 看主控 | 套件主控常是 4MB 版——下单必确认规格 |
| S3 SuperMini ¥15 常见款 | ¥35-45 | ❌ | **4MB Flash + 2MB PSRAM（FH4R2），跑不动 Fork——省错钱的坑** |
| ESP32-C3 SuperMini（¥8-12） | ¥25-35 | ❌ | 无 PSRAM，完整 xiaozhi 栈无缘；自写极简客户端=新固件线，性质等同 Air780E 开发量级 |

**硬线**：主控必须 S3 + 16MB Flash + 8MB PSRAM（底线 8MB Flash），低于此线白买。**C3 不上主路线**——C3 的现成实现就是 FoloToy（¥99 整机含壳电池屏，09-21 到货），比 C3 SuperMini 拼装划算；去音频输出（D20）省 ¥8-10 成立。XIAO vs SuperMini 组合：+¥30-60 买到集成度（PDM 麦/充电板载）与最小形态。

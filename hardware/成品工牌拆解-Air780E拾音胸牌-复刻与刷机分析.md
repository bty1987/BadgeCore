### 1.1 实物照补充（2026-09-23 上手核对）

| 观察 | 结论 |
|---|---|
| 金色金属件 ×2（板顶 + 飞线） | **IPEX(u.FL) 4G 天线座与馈线插头，不是按键**；照中馈线脱落未插回——测 4G 前须对位轻按插回（IPEX 易损）；USB 识别不受影响 |
| 电源开关 | ★修正（09-23 实测）：红色元件非滑块，只是元件（疑似 LED）；实物另有开关，可开机、可双击 |
| LED 指示（09-23 实测） | 开机：蓝灯闪 → 蓝灯常亮（疑为搜网 → 注网成功）；**双击开关 → 绿灯**（疑为录音中）；无其他灯效 |
| USB 枚举（09-23 实测） | **✅ 枚举成功**：`VID_19D1 PID_0001`（合宙确认），复合设备 4 接口——RNDIS 网卡(MI_00)/普通log(MI_02)/底层log(MI_04)/AT口(MI_06)，与合宙官方端口规律一致；**780 系官方免 USB 驱动**（docs.openluat.com/common/usb_drv/）。产品固件未关 USB、无存储门槛——**关键异常：枚举后数秒设备从系统消失**（疑固件 USB 门控/复位），AT 口探测与下载模式为下一步；「能连上≠能烧入」仍待验 |
| 底部边缘排孔/焊盘一排 | 疑似调试串口/扩展焊盘外露——USB 烧录若被厂商锁，可走 UART 兜底（刷机利好） |
| 双麦 FPC | 两条橙色 FPC（标 1/2）经右侧两个 ZIF 座上板，印证 §1 双麦阵列 |
| 其他确认 | 电池 JST 红黑线在板底；右下角 1V8_GND 测试点；正面未见明显按压按键（无 BOOT 键，进下载模式或需短接焊盘） |
| 仍待确认 | 中部黑色方块用途；白色 BTB 用途；SIM 位置（翻面确认）；LED 位置 |

### 1.2 背面焊盘图（2026-09-23 实拍，刷机关键）

背面沿边缘一排镀金测试焊盘，09-23 用户上手核对丝印：行内含 **`GND`，其旁紧邻 `AIR780EP_BOOT` 与 `AIR780EP_RET`（=RESET）**，另有 SWD/UART/音频类焊盘（具体逐颗丝印以实物为准，照片分辨率不足以精确读全）；USB-C 附近金点为 `CHG`（充电检测，VBAT 域，勿接 BOOT）。

| 焊盘 | 用途 | 对我们的意义 |
|---|---|---|
| **BOOT** | **上电前**拉高到 1.8V(VDD_EXT) → USB 下载模式（bootrom）；拉低无效、开机后短接无效（合宙官方文档确认） | **刷机入口**；板上无标 1V8 的点（USB 下方金点实为 `CHG` 充电检测，非 1.8V——09-23 实物纠正），拉高电源备选：借同排 `RESET`/`SWDIO` 的内部 1.8V 上拉 |
| SWCLK / SWDIO | SWD 调试口 | 可读写底层 Flash——日后分析产品固件的口子 |
| TX01/RX01、TX02/RX02 | 两路 UART | USB 被门控时的 log/AT 兜底（需 USB-TTL 3.3V） |
| AUDOP / AUDREF-AGND | 模拟音频输出/参考地 | 可外接耳机验证音频通路 |
| RESET / GND | 复位 / 地 | 配合调试 |
| 其他 | 丝印 `DS8511-EP-2_20260` 疑为 PCBA 版本号；USB 口旁红色 LED（充电指示） | 版本留档 |

## 2. 产品形态判定

4G Cat.1 拾音胸牌（DuDuTalk 同类）：双麦拾音 → 模组内录音/编码 → 4G 上传云端 → 远程启停。210mAh 小电池印证产品逻辑 =「远程控制的间歇拾音」，非常开常录。

**与 BadgeCore 的路线关系**：与 D21（基本不搞屏幕）、D20（无喇叭）的「纯采集」方向**完全同构**，且自带 4G——正好补上 §需求① 里「WiFi 方案无 4G、移动实时上传缺位」的短板。

## 3. 可复刻性分层判定

| 层面 | 判定 | 说明 |
|---|---|---|
| **功能复刻** | ✅ 且比 ESP32 路线更贴 | Air780E 生态便宜成熟：开发板 ~¥40、模组 ~¥20、参考设计与 LuatOS 例程公开；「录音→编码→4G 上传」是合宙官方 demo 级场景 |
| 1:1 克隆此板 | ❌ 不建议 | 无原理图、私模器件 + 定制 FPC、知识产权风险、不经济；功能自研即可 |
| **刷这台成品** | ⚠️ 可尝试（成功 = 零成本样机） | 见 §4 |

## 4. 刷机可行性（为我们所用）

**原理**：Air780E 属合宙 LuatOS 体系，USB 下载口 + 官方 Luatools 烧录；底层固件公开可重刷，脚本区可擦写。商业产品可能启用脚本加密/烧录锁——注意**「能连上」≠「能烧入」**，厂商锁写的概率约一半，实测才知道。

**判定**：未锁 → 这台成品直接刷成 BadgeCore 的 4G 拾音客户端，双麦/电池/结构件全复用，零硬件成本；已锁 → 放弃刷机转自研板（合宙模组公开销售，量产无合规障碍）。

### 4.1 刷机实测日志（2026-09-23）

**开机窗口抢端口成功**：Luatools 常驻时插板开机，COM4（用户虚拟串口/AT）、COM5（diag）、COM6（soc log）全部在窗口期绑定成功，抓到完整启动日志：

- 底层：`SDK base line V017_p001.011`，模组 `Air780EPM_A11`，芯片 `EC718PM`
- **产品固件 = 合宙 LuatOS 脚本固件**：项目名 `TEST_EC718PM`（**厂商拿测试工程直接出货，未改名**），版本 1.0.5，项目 key `FFyNIwQGOr7trl7K9cZUFaa9ooGcNYEF`
- 脚本功能自白：fskv 存储、SPI 任务、TCP 数据处理任务、网络状态通知、`loc_scan`（LBS 定位——印证 §7.5 竞品定位=基站定位）、开机 OTA 关闭、异常即重启、gpio23 输出（疑似 LED/麦使能）
- `调试模式: 关闭`
- **USB 被掐 = 脚本层行为**：开机时 LuatOS 默认枚举 USB，注网后脚本收掉（蓝灯常亮后数秒消失）——不是底层锁
- 窗口期约数秒，Luatools 常驻可稳定抢到端口 → **软件重启进下载模式路线可行**（不必碰 BOOT 焊盘）

**下一步**：Luatools「下载固件」必须选 **Air780EPM**（EC718PM，与 Air780E 的 EC718E 固件不通用！），LuatOS 正式版 core → 点下载进入等待 → 板关机再开机 → 窗口期工具发重启进下载命令 → 常驻下载口 → 烧录。烧入成功 = 未锁；报禁止烧录/校验失败 = 厂商锁，转自研板。

**实测补充（09-23 下午）**：Luatools + 最小 main.lua 项目合并通过，但下载报「模块重启超时」——**证实 EP 系（EC7xx）软件触发进下载无效，必须上电前硬件拉高 BOOT**（EC618 的免 boot 是老款专属）。板上无 1V8 标注点（USB 旁金点为 CHG，VBAT 域勿碰 BOOT），拉高电源候选：借同排 RESET/SWDIO 内部 1.8V 上拉 → 失败则查 Air780EPM 引脚找 VDD_EXT 或用 CH340 走 UART 烧录（main_uart=TX01/RX01，官方支持路径）。

**当日收尾状态（09-23 傍晚）**：BOOT↔RET 短接上电后模组进入异常循环（蓝灯狂闪不常亮、USB 不枚举）；撤短接后蓝灯仍闪——**蓝灯逻辑由厂商脚本驱动，脚本能跑即闪存/CPU/固件完好，无硬件损伤证据**。待办：①插回 IPEX 天线（金色馈线自拆解后脱落，蓝灯闪=搜网无天线）②USB-C 焊点接触不良排查（换后面板口/按压测试）③**CH340 串口烧录为保底路径**（TX01/RX01/GND，¥10 次日达，不经 USB 口，Luatools 固件项目已配好）——串口烧录完成「烧录锁」终局判定。



**风险与边界**：变砖概率低（底层固件损坏也可经下载模式救回）；原厂脚本加密则读不出（我们也不需要读）；**商用边界**：研究验证用可以，量产必须自研板 + 自购模组；若设备属客户在册资产，刷机前先确认所有权/合同。

## 6. 与现有路线的关系

- 架构原则本就支持多板型共存（`device` 字段分流）：**前台 WiFi = ESP32 卡片（v5 外壳）+ 移动 4G = Air780E 线（本板刷机或自研）**，服务端一套。
- 外壳红利：此板目测 ~30×52，比 85×54 卡片更小巧——v5 参数化外壳改 `pcb_l/pcb_w` 即可适配出更小形态。
- 续航账要加 4G 一列：Cat.1 PSM 待机 mA 级以下（优于 WiFi 连接待机），但连续推流 TX 峰值大、耗电高于 WiFi；210mAh ≈ 连续推流 ~1h——印证「远程启停间歇拾音」，与 §3.2 的「插电常驻/间歇推流」原则一致。

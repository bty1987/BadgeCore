## 1. 产品定位

- **Slogan**：「每次沟通都是进步，每个客户都是机遇」/「先进销售团队，先用SaleSmart」
- **本质**：AI 录音工牌（硬件）+ 销售会话智能 SaaS（软件）的软硬一体产品
- **基础设施**：云学堂（yxt.com）「灵犀」平台孵化，前端代号 NovaGuide v3.6.3，企业后台名「SaleSmart企业管理后台」
- **目标行业**：家装（演示数据）、地产、汽车4S、医美等线下重咨询销售场景
- **示例组织**：华东一部；演示客户：南京锐驰租赁、合肥远行商贸、宁波海丰物流

## 2. 产品形态：三端 + 硬件

| 端 | 路由前缀 | 角色 |
|---|---|---|
| 销售端（PC Web） | `/#/coach/*`（实测）与 `/commander/*` | 一线销售/教练，实测账号为教练角色 ★ |
| 管理后台 | `/#/admin/*` + `/#/manage/*` | 企业管理员：配置模型/字段/权限 ★ |
| 移动 H5 | `/postmeet-xmate-h5/` | 会后随行：安排会议、纪要、我的客户、学习中心、本地录制 |

| 硬件工牌 | 通过 App 蓝牙桥接 | 录音采集 |

## 3. 硬件工牌链路（软件侧还原）★+代码

**设备管理 API**（blue.x-mate.com）：
- `rest/api/device/bind` 绑定 / `rest/api/device/unbind` 解绑 / `rest/api/device/info` 设备信息
- `rest/api/v1/badge/operation-log/query|export` 工牌操作日志查询/导出（BadgeLogDrawer 抽屉）
- 状态轮询 `getBadgeInfoAction`（badgePollingTimer）+ WebSocket 推送（`initBadgeWebSocketListener`）
- WS 通道：`wss://api-phx-ali.yunxuetang.cn/xmatews/ws`，认证带 token

**状态监测项**：工牌编号、工牌当前状态、电量（BatteryIndicator 组件）、信号强度、在线/离线
- 提示文案实证 ★：「工牌信号较弱，录音上传可能较慢」「工牌离线（可能未开机或无信号），开机联网后录音将自动上传」「低电量停录」「录音尚未上传，App保持登录并联网后将自动上传」

**录制链路**：
- 蓝牙连接手机 App（RecordController 检查蓝牙连接状态/解析蓝牙数据）
- 「此录制正在另一设备上进行，请在原设备完成后再操作」→ 设备级录制互斥
- 工牌物理录制按键（管理后台可配置开关 ★）
- 蓝牙设置（管理后台配置项 ★）
- 固件升级（OTA）
- 录音上传：支持 mp4/mp3/m4a/aac/wav，单文件 ≤ 1GB，时长 ≤5h ★（上传录音弹窗）
- 长录音：每 10 分钟且文本超 500 字自动生成分段总结 ★

**全局配置中与硬件/ASR 相关的项**（★ 截图 admin-global.png）：
语音识别热词 / ASR模型 / 发言人标注设置 / 语音切分设置（客流切分）/ 蓝牙设置 / 工牌物理录制按键 / 实时辅助

## 5. 销售端功能（★ 实拍）

- **首页**：问候+金句卡；沟通次数/时长（本周~累计，团队人均对照）；能力评估雷达（个人vs团队平均）；任务达成；今日日程/待办；情报中心
- **发起沟通**三入口：立即录制 / 安排沟通（沟通计划）/ 上传录音
- **指挥舱**（commander）：客户追踪器（我的关注）、实时沟通看板
- **沟通列表**：处理状态、赋能状态、多筛选、导出
- **客户列表**：列=客户名称/沟通环节/预警/客户分析/客户画像/沟通动态/沟通次数/协同跟进人/待办/竞争对手/销售负责人
- **案例库**：优秀客户案例（行业/ToB-ToC/业务标签/摘要/浏览数）+ 金牌话术（销冠话术沉淀）

## 6. AI 能力清单（代码+文案还原）

1. **实时 ASR**：WebSocket 流式转写（xmateasr）、实时字幕、ASR 连接状态管理
2. **说话人分离与标注**：声纹标注、修改发言人、发言人身份标注后生成报告
3. **中期总结**：每10分钟/500字自动分段总结
4. **沟通分析报告**：全文摘要+分段摘要；客户立场（认同点/顾虑点/未提及项）；客户关注点；竞品提及+声量雷达图；意向度评估（成交模型结果）；痛点与需求分析；应对策略建议
5. **违规检测**：可配置违规项（含「非违规判定说明」，如：结合上下文识别「引导意图」而非仅匹配关键词——说明是 LLM 语义判活，不是关键词匹配）
6. **实时辅助**（realtime-assist）：规则状态 API；机构级开关「实时辅助未开启，请联系管理员开启」
7. **AI 智能体（访前准备）**：产业信息挖掘机/企业信息侦察机/产品价值演绎家/客户追踪器/商机追踪器 → 准备清单、客户FAQ、竞品分析、应对策略
8. **Ask AI**：SalesCoach（销售视角）/SalesCommander（管理视角）问答 + 定时任务推送（数据时间范围由 AI 从任务描述解析）
9. **教练赋能**：销冠话术提炼（「N条销冠话术」）、即时赋能教练、能力项评估、任务达成评估、案例库沉淀
10. **风险预警**：沉默/立场反对/竞品提及
11. **销售方法论内置**：SPIN销售法、价值销售、信任式销售 + 销售书籍知识库（《人性的弱点》《从失败到成功的销售经验》等，人物标签：尼尔·雷克汉姆、布莱恩·崔西、乔· ' ·吉拉德等）

## 7. 业务闭环（推断+证据）

```
绑定工牌 → 开始/安排沟通 → 录音(蓝牙工牌/手机/上传) → 实时ASR+字幕
→ 说话人标注 → AI分析(立场/竞品/意向/违规/任务达成/能力评估)
→ 生成报告 → 沉淀(客户画像/金牌话术/案例库) → 赋能(教练辅导/学习中心/AskAI)
→ 管理洞察(团队看板/九宫格/排行榜/效能报告) → CRM同步
```

## 8. 权限体系

- 视角：销售端/团队端/管理后台三视角切换（「切换至销售端/团队端/管理后台」）
- 角色等级（1级系统角色+自定义），权限树=导航×操作×数据范围
- 数据权限：本人/团队/部门经理/虚拟团队负责人/创建人及团队管理者；「无权访问该部门数据」
- 分享权限：互联网获得链接者/企业内/团队内/分享范围人员，可加密码、链接有效期
- 沟通记录查看/删除权限独立配置（全局配置 ★）

## 10. 对我方「全员数字工牌」的差异化启示

SaleSmart 只覆盖「销售沟通录音分析」场景；我方「员工数字工牌」需额外覆盖：
1. 通用身份载体：门禁/考勤/工卡展示（NFC/二维码/人脸关联）
2. 信息通知：消息提醒（震动/屏幕/LED）
3. 定位与安全：工位/园区定位、电子围栏（竞品云知声已有）、紧急呼叫
4. 全员 vs 销售双模式：非销售员工低功耗待机，销售员工录音长续航
5. 组织集成：AD/企业微信/钉钉组织架构同步（SaleSmart 走云学堂 SSO，我们需自建或集成）

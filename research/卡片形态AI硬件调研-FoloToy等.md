### 2. 对 BadgeCore 的价值判断

**FoloToy AI Passport——形态参考价值高，不建议作开发载体：**
- 价值：它是目前**形态最接近我们量产工牌的开源设备**——卡片式 + TFT 屏 + ES8311 全双工音频 codec（支持录音）+ NFC 被动标签 + 520mAh 电池 + 三按键 + 电量计。这套硬件组合与 02 册量产定义（02 册 §1/§2）高度同构，其引脚定义（bsp_pins.h）、LVGL 布局、"NFC 被动标签不连 MCU 做身份碰读"的设计都是**量产阶段的免费参考**。
- 局限：ESP32-C3 单核无 PSRAM（free 约 170KB）撑不起 4 麦阵列/波束成形/持续转写管道；官方不开原理图 PCB（复刻需自行画板）；**与本会话已验收的开发载体 1.75C（S3 双核 + PSRAM + 双麦阵列）相比，音频算力明显更弱**。
- 结论：**不采购、不替换 1.75C**；其 BSP 思路与 NFC 标签设计吸收进 02 册量产参考（FW-08/NFC 章节可引用其"被动 NFC 做身份碰读"方案——与我们 05 册 ALL-102 动态二维码互补）。

**钉钉 DingTalk A1 价格补全竞品对照**：青春版 499 元 / Pro 1299 元（待验证）——比我方定价带（399~599）偏高，验证 08 册 §3 成本优势判断。

**成本口径警示（重要）**：文档 §6 的"500 片 BOM ¥27~50"是**简化语音卡片的成本**（单麦、无 4 麦阵列、无墨水屏、无 NFC SE、无 4 麦波束 DSP）——**不可与 02 册的 BOM ≤180 元目标直接对比**。我方 BOM 包含 4 麦数字阵列 + 墨水屏 + NFC 安全单元 + IMU + 600mAh 电池，两者是不同物种。但文档的"NRE 摊销、钢网费、山寨元件风险、百件以上再找 PCBA"等批量生产方法论直接适用。

**开源协议警示（与我们既有结论一致）**：小智生态部分硬件项目 GPL 3.0 / "仅供学习交流"，商用前确认授权——与 DayoTag、QS668 的教训同一条线（DECISIONS.md D7）。

# 卡片形态 AI 硬件 DIY 与 FoloToy AI Passport 复刻指南

## 1. 核心结论

- FoloToy AI Passport 本身是开源 AI 硬件项目，适合复刻和二次开发。
- 官方未公开完整原理图、PCB 和 BOM，复刻需参考官方引脚定义和社区方案。
- 如果只需要"卡片形态 + 语音输入"，可选择：
  - 成品：小智墨伴、钉钉 DingTalk A1 等。
  - DIY 套件：小智 AI 套件、M5Stack Cardputer。
  - 超薄卡片复刻：立创开源硬件平台上的"ESP32 小智 AI 超薄卡片版"。
  - 完全自主设计：ESP32-S3 + INMP441 麦克风 + MAX98357A 功放。
- Bouija 和 Muxcard 均不支持录音，不适合语音输入需求。
- 批量生产可降低单件成本，但存在 NRE 费用、开源协议限制和元器件质量风险。

## 2. FoloToy AI Passport 概述

FoloToy AI Passport 是一款基于 ESP32-C3 的开源 AI 硬件，主要特点：

- 主控：ESP32-C3
- 显示：ST7789P3 TFT LCD，240 × 320
- 音频：ES8311 编解码器，支持播放和录音
- 交互：UP / DOWN / OK 三枚物理按键
- 连接：Wi-Fi、BLE、Type-C USB
- 扩展：NTAG213 NFC 被动标签、CW2017 电量计
- 电池：520mAh 锂电池
- 开发资源：官方提供 `FoloToy/ai-passport` 仓库、硬件开发指南和 BSP 源码

官方仓库未提供原理图、PCB 和 BOM，复刻时需要参考 `bsp_pins.h` 引脚定义，或寻找社区类似方案。

## 3. 类似可 DIY 的卡片形态 AI 硬件

### 3.1 M5Stack Cardputer

- 芯片：ESP32-S3
- 特点：信用卡大小，自带 56 键键盘、屏幕、扬声器、麦克风
- 价格：约 358 元，M5Stack 企业店有售
- 优点：硬件成熟，社区活跃，可刷多种 AI 固件
- 注意：无 PSRAM，堆内存约 300KB，复杂音频和屏幕任务需调优

### 3.2 小智 AI 生态

- 核心项目：`xiaozhi-esp32`
- 目标：Build your own AI friend
- 支持硬件：ESP32-S3-BOX3、M5Stack CoreS3、AtomS3R + Echo Base、One ESP32-S3 等
- 特点：原生语音对话，支持 MCP 控制 GPIO、音量、灯光等
- 购买：淘宝可搜"小智 AI 套件"，价格约 69.9 元至 285 元

### 3.3 小智墨伴 / Xiaozhi Card

- 形态：卡片式成品
- 尺寸：约 84.0 × 54.0 × 8.0 mm
- 功能：内置麦克风、扬声器，支持 Wi-Fi 和 4G
- 价格：约 299 元，淘宝有售
- 适合：不想自己焊接，希望开箱即用

### 3.4 Bouija 名片

- 形态：85mm × 54mm PCB 名片
- 主控：ESP32-S3
- 输出：40 颗 WS2812B LED 组成通灵板图案
- 功能：本地运行 LLM，用 LED 显示文本
- 缺点：无麦克风，不支持录音和语音输入
- 资源：GitHub 仓库 `pham-tuan-binh/bouija`

### 3.5 Muxcard

- 形态：信用卡大小计算机
- 主控：ESP32-C3
- 配置：1.54 英寸电子墨水屏、NFC、加速度计、电池
- 特点：追求约 1mm 超薄厚度
- 缺点：无麦克风，不支持录音
- 适合：纯视觉、NFC 交互的极客卡片项目

### 3.6 其他相关方案

- OpenGlass：开源智能眼镜，感知与计算分离
- 树莓派方案：Pi-C.A.R.D、LLM-8850 Card 等，算力更强但体积较大
- 成品 AI 录音卡片：钉钉 DingTalk A1、科大讯飞 AI 录音卡片、百智 WiseNote、Plaud Note Pro、灵光闪记卡等

## 4. 卡片形态 + 语音输入方案推荐

### 方案一：M5Stack Cardputer

- 难度：低
- 特点：自带麦克风、扬声器、键盘、屏幕
- 适合：快速体验、刷 AI 固件、二次开发
- 价格：约 358 元

### 方案二：小智 AI 超薄卡片版

- 难度：中
- 平台：立创开源硬件平台 OSHWHub
- 项目名：ESP32小智AI 超薄卡片版 超稳定 大元件易复刻
- 特点：元件大、模块化、复刻简单，原生支持语音对话
- 复刻成本：约 60 元
- 注意：需自己下载 PCB 文件打样、采购元件、焊接、烧录固件
- 教程：B 站有"卡片小智组装教程"

### 方案三：模块自搭

- 主控：ESP32-S3-WROOM-1/N8R8，内置 8MB Flash 和 8MB PSRAM
- 麦克风：INMP441 数字 I2S 麦克风模块
- 功放：MAX98357A I2S 音频放大器 + 小喇叭
- 交互：按键触发录音
- 供电：锂电池 + 充电管理模块
- 优点：形态和功能完全自主定义
- 缺点：需要一定硬件设计和焊接能力

### 方案四：小智墨伴成品

- 难度：无
- 特点：开箱即用，卡片形态，内置麦克风、扬声器
- 价格：约 299 元
- 适合：不想 DIY，但需要语音输入和卡片形态

## 5. FoloToy AI Passport 复刻硬件清单

### 5.1 核心硬件规格

| 子系统 | 器件 / 方式 | 总线 / 资源 | 关键参数 |
| :--- | :--- | :--- | :--- |
| 主控 MCU | ESP32-C3 | - | RISC-V 单核 160MHz，8MB Flash，无 PSRAM |
| 显示 | ST7789P3 TFT LCD | SPI2，40 MHz，mode 0 | 240 × 320 分辨率，竖屏 RGB565 |
| 背光 | LCD LED 背光 | GPIO21，LEDC | 5 kHz / 10 bit，支持 PWM 调光 |
| 音频编解码 | ES8311 | I2C 控制 + I2S0 全双工 | 支持播放和麦克风录音，全双工 PCM |
| 按键 | UP / DOWN / OK 三键 | GPIO0 / ADC1_CH0 | 电阻分压，共用单个 ADC 引脚 |
| 电池电量计 | CW2017 | 共享 I2C0，地址 0x63 | 读取电池 SOC 与电压，可缺省 |
| 电池电芯 | 520mAh 锂电池 | - | - |
| NFC | NTAG213 被动标签 | 不连 MCU | 仅手机碰读身份信息 |
| USB | Type-C 2.0 | USB Serial/JTAG GPIO18/19 | 用于烧录和日志 |
| 电源 | 独立硬件电源键 | - | 区别于三功能键 |

### 5.2 复刻要点

1. 官方未公开原理图、PCB 和 BOM，需要根据 `bsp_pins.h` 自行设计或参考社区方案。
2. ESP32-C3 无 PSRAM，可用内存约 370KB，free 约 170KB，LVGL 大页面和整屏位图缓冲吃紧。
3. 大尺寸 UI 素材建议存放在 Flash 中，按需分页读取。
4. NTAG213 是被动标签，不连接 MCU，仅用于手机读取身份信息。
5. CW2017 电量计可省略，以简化设计。
6. 可参考社区类似方案：在 OSHWHub 搜索"ESP32-C3 + ES8311 + NS4150B"等关键词。

## 6. 成本与批量生产分析

### 6.1 个人 DIY vs 批量生产预估

以 500 片中小批量为例：

| 成本项目 | 个人 DIY（单件） | 批量生产（500 片预估） | 说明 |
| :--- | :--- | :--- | :--- |
| 主控模组 ESP32-S3 | ¥20 | ¥12 - ¥15 | 批量采购可降至约 ¥31，自行贴片可控制在 ¥15 内 |
| 麦克风 INMP441 | ¥6 | ¥2 - ¥4 | 批量采购单价可低至 ¥2.68 起 |
| 功放 MAX98357 | ¥5 | ¥2 - ¥3 | 批量采购典型降幅 |
| PCB 与贴片 | ~¥10 | ¥5 - ¥15 | SMT 贴片约 ¥0.008 - ¥0.015/点 |
| 其他元件 | ~¥5 | ¥2 - ¥3 | 电源管理、Type-C、电阻电容等 |
| 物料 + 加工成本 | ~¥46 | ~¥23 - ¥40 | 不含 NRE |
| NRE 费用摊销 | 无 | ¥4 - ¥10 | 工程调试费、钢网费等 |
| 单件总成本 | ~¥46 | ~¥27 - ¥50 | 批量生产可节省约 20% - 40% |

> 以上为基于公开 BOM 和行业报价的估算，实际成本会因设计复杂度、订单量、供应商选择而浮动。

### 6.2 批量生产注意事项

- NRE 费用是固定投入：工程调试费约 ¥1000 - ¥2000，钢网费约 ¥150 - ¥500。数量越大，单件摊销越低。
- 如果只做几十片，总成本可能反而高于个人 DIY。
- 避免山寨元器件：非正规渠道 ESP32-S3 可能存在信号问题。
- 开源协议限制：许多小智 AI 硬件项目采用 GPL 3.0 等协议，仅供学习交流，商业售卖需确认授权。
- 批量生产前建议与多家 PCBA 服务商沟通，获取具体报价。

## 8. 选择建议

- 想直接当工具用：优先考虑钉钉 DingTalk A1 青春版，性价比高，软件生态成熟。

## 9. 风险与注意事项

- 开源项目通常没有成品，淘宝搜不到属正常现象，需要自行打样、采购、焊接和烧录。
- 价格和库存具有时效性，购买前请以最新页面为准。
- 开源协议可能限制商业用途，批量销售前务必确认授权。
- ESP32-C3 无 PSRAM，音频、屏幕和 AI 任务需要仔细优化内存。
- 批量生产存在 NRE 费用、贴片良率和元器件真假风险。
- 语音交互项目对麦克风、功放、电源噪声和结构设计有一定要求，建议先做单件验证。
